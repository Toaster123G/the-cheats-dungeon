# About project

2D платформер, разработанный на движке Unity.

- Движок: Unity 
- Язык: C#
- Жанр: 2D-платформер

---

## Как установить репозиторий локально на ПК

1. На странице репозитория на GitHub нажимаем зелёную кнопку **Code** и копируем HTTPS-ссылку.
2. Открываем меню системы: `Win + X` и выбираем **Terminal** (обычный терминал).
3. Переходим на рабочий стол командой:

```bash
cd Desktop
```

4. Клонируем репозиторий (вставляем скопированную ссылку):

```bash
git clone https://github.com/Toaster123G/the-cheats-dungeon.git
```

5. Заходим в папку проекта:

```bash
cd the-cheats-dungeon
```

---

## Какие зависимости необходимо установить в проект и как

1. Устанавливаем **Unity Hub** — https://unity.com/download
2. Через Unity Hub устанавливаем версию редактора **Unity `6000.3.4f1`** (важно ставить именно эту версию, чтобы проект открылся без ошибок).
3. В Unity Hub нажимаем **Add → Add project from disk** и выбираем папку `the-cheats-dungeon`.
4. Открываем проект. При первом запуске Unity **сам скачает и установит все пакеты** из `Packages/manifest.json` (Input System, URP, 2D Tilemap и др.) — вручную ничего ставить не нужно.

## Как отправить изменения на репозиторий

> **ВНИМАНИЕ:** ПРОВЕРЬТЕ, ЧТО ВЫ НА СВОЕЙ ВЕТКЕ, КОМАНДОЙ:
>
> ```bash
> git branch
> ```
>
> Текущая ветка отмечена звёздочкой `*`. Не работайте напрямую в ветке `main`.

1. Создаём свою ветку (если ещё не создана) и переключаемся на неё:

```bash
git checkout -b имя-ветки
```

Если ветка уже есть — просто переключаемся на неё:

```bash
git checkout имя-ветки
```

2. Проверяем, какие файлы изменились:

```bash
git status
```

3. Добавляем все изменения:

```bash
git add .
```

4. Сохраняем изменения с комментарием (описываем, что сделали):

```bash
git commit -m "описание изменений"
```

5. Отправляем изменения на GitHub (вместо `имя-ветки` подставляем свою ветку):

```bash
git push origin имя-ветки
```
